# Portfólio — Arthur Nunes Freitas

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript, usando Vite para desenvolvimento local.

## Principais recursos

- Design editorial técnico e identidade visual `ANF-HW`;
- Layout responsivo para desktop, tablet e celular;
- Animações de entrada, marquee, indicadores de status e microinterações;
- Navegação ativa e menu móvel acessível;
- Preferência de movimento reduzido respeitada;
- Cards de projeto expansíveis e metadados para compartilhamento.

## Rodar no VS Code

1. Abra esta pasta no VS Code.
2. Abra o terminal integrado.
3. Execute `pnpm install` (ou `npm install`).
4. Execute `pnpm dev` (ou `npm run dev`).
5. Abra o endereço exibido no terminal, normalmente `http://localhost:5173`.

## Criar a versão de produção

Execute `pnpm build` ou `npm run build`. Os arquivos finais serão gerados na pasta `dist`.
